📚 COURSE STRUCTURE
================================================================================

Level A1 (Days 1-20):
  • Present tenses (be, do, have)
  • Basic past (was, were, did)
  • Present perfect introduction
  • Simple questions and negatives

Level A2 (Days 21-68):
  • Present and past perfect
  • Passive voice
  • Modals (can, could, must, should, may)
  • Articles and determiners
  • Adjectives and adverbs

Level B1 (Days 69-88):
  • Complex sentence structures
  • Conditionals (0, 1, 2)
  • Relative clauses
  • Prepositions and phrasal verbs
  • Reported speech

Final (Days 89-90):

  • Final evaluation
  • Certificate of completion

📞 SUPPORT & TROUBLESHOOTING
================================================================================

Common Issues & Solutions:

Q: Progress not saving?
A: Enable localStorage in browser settings
   Check browser console for errors (F12)

Q: Dark mode looks broken?
A: Click theme toggle (🌙) in header
   CSS variables should apply

Q: Can't complete lesson?
A: Fill at least one exercise first
   Try refreshing page

Q: Exercise not loading?
A: Check browser console (F12)
   Try clearing localStorage: localStorage.clear()
   Reload page

Q: Want to reset progress?
A: Settings → Reiniciar Curso → Confirm

Q: Need to back up progress?
A: Settings → Descargar Progreso (downloads JSON)

Q: Want to restore backup?
A: Settings → Importar Progreso (select JSON file)

Debug Commands (in browser console):
  • runCourseValidation() - Check data integrity
  • app.state - View current state
  • localStorage.getItem('essentialGrammar90Days') - View stored data
  • localStorage.clear() - Erase all data
